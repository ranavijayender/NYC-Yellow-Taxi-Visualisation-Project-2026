# NYC Yellow Taxi Data Visualisation – November 2024

## Project Overview

This project presents an explanatory data analysis of NYC Yellow Taxi trips during November 2024. The analysis explores patterns in taxi demand, trip characteristics, fares, payment behaviour, and tipping using Python-based data visualisations.

## Dataset

The project uses the NYC Yellow Taxi Trip Records for November 2024 published by the New York City Taxi and Limousine Commission (NYC TLC).

Dataset source: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

The original Parquet dataset is not included in this repository due to its large file size.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis

The project follows four main stages:

1. Data exploration and identification of data quality issues
2. Data preprocessing and cleaning
3. Data visualisation and development of seven explanatory insights
4. Discussion, business implications, recommendations, and conclusion

The visualisations examine taxi demand by hour and day, trip-distance patterns, the relationship between distance and fares, payment methods, tipping behaviour, and average fares throughout the day.

## Repository Files

- `B106.ipynb` – Complete Jupyter Notebook containing the analysis, code, visualisations, and interpretations.
